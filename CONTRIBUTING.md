# Contributing

Thanks for looking. Aegis-Seal is a small, deliberately scoped verification
crate — contributions that keep it small, honest, and readable are the ones
that fit.

## Ground rules

- **Scope.** This crate does three things: Ed25519 signing with hardened key
  custody, a hash-chained audit ledger, and secret/entropy scanning — plus
  independent verification of MACK vault checkpoints. It is a verification
  tool, not a platform. Pull requests that grow it into a framework will be
  closed with thanks.
- **The checkpoint byte layout never drifts.** `verify-checkpoint` exists to
  check signatures produced by the MACK vault's checkpoint scheme
  (`"mack-checkpoint-v1"` ‖ seq as 8-byte big-endian ‖ head hash). The test
  vector in `src/checkpoint.rs` was generated by the vault's own signing
  code and is pinned on purpose: if a change makes that vector fail, the
  change is wrong, not the vector.
- **Key custody is a design rule, not a preference.** The private key is
  never printed, logged, or exported in text form; key files are owner-only
  (0600) and never overwritten. Contributions that add a key export path
  will not be merged.
- **Honesty in docs and tests.** Every claim in the README must match what
  `cargo test` proves. If a change alters a limitation, update the
  limitation where it is documented (README, CHANGELOG, SECURITY.md) in
  the same PR.
- **No new dependencies without discussion.** The dependency list is
  deliberately short (ed25519-dalek, rand, sha2, subtle, zeroize, hex,
  thiserror). Open an issue first.

## Building and checking

```bash
cargo test
cargo fmt --all -- --check
cargo clippy --all-targets -- -D warnings
```

All three must pass. CI runs exactly these commands. The library forbids
`unsafe` code and denies `unwrap` / `expect` / `panic` in library code —
keep it that way.

## Reporting bugs

Open an issue with: what you ran, what you expected, what happened, and
your `rustc --version`.

## Security issues

Don't open a public issue — see `SECURITY.md` for the private reporting
address.
